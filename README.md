# To-Do List App ✅

A simple and responsive **To-Do List Application** that helps users manage daily tasks. Users can add, edit, delete, search, and mark tasks as completed. The app stores tasks using browser Local Storage, so data remains saved even after refreshing the page.

## 🚀 Features

* ✅ Add new tasks
* ✏️ Edit existing tasks
* 🗑️ Delete tasks
* ☑️ Mark tasks as completed
* 🔍 Search tasks
* 📌 Filter tasks (All, Completed, Pending)
* 💾 Local Storage support
* 📱 Responsive design for different devices

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Local Storage API

## 🎯 How It Works

* Enter a task in the input field.
* Click the **Add Task** button.
* Manage tasks using edit, delete, and complete options.
* Tasks are automatically saved in your browser.
